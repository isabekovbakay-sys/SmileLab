# SmileLab

Android-приложение стоматологической клиники SmileLab (Бишкек) для пациентов.
React Native + Expo SDK 57 + TypeScript (strict). Два языка: кыргызский и русский.

Главная задача приложения — за минимум касаний довести пациента до записи или звонка в клинику.

## Что умеет

- **Главная**: герой с одной кнопкой «Записаться на приём», под ним без прокрутки — «Позвонить», WhatsApp, Telegram, «Адрес» (2ГИС) и статус «Сегодня открыто до 19:00» (обновляется раз в минуту). Дальше — ближайшая запись, услуги и цены, имплантация, врачи, «Не знаете, с чего начать?».
- **Запись за 3 шага**: услуга → врач, день и время (утро / день / вечер, автоматически выбран ближайший день со свободным временем) → имя, телефон +996, комментарий. Со страницы услуги запись начинается сразу со 2-го шага.
- **Заявка в WhatsApp**: приложение открывает WhatsApp клиники с готовым текстом (услуга, врач, дата, время, имя, телефон, комментарий). Перенос и отмена тоже отправляют сообщение.
- **Мои записи**: предстоящие и история, перенос (один экран), отмена через подтверждение, «Записаться снова».
- **Профиль**: имя и телефон подставляются в запись, язык, удаление данных с телефона.
- **Контакты, «О клинике», врачи, услуги с этапами и FAQ, политика конфиденциальности**, экран 404 и перехват ошибок.

## Быстрый старт

```bash
npm install
npx expo start          # отсканируйте QR в Expo Go на Android
```

| Команда | Что делает |
| --- | --- |
| `npm run check` | типы (`tsc`), линтер (`eslint`), тесты логики (`node --test`) |
| `npm run build:apk` | APK через EAS для прямой установки |
| `npm run build:aab` | AAB через EAS для Google Play |
| `npm run build:apk:local` | APK локально (нужен Android SDK) |
| `npm run bundle:android` | проверочный экспорт JS-бандла Android (Hermes) |
| `npm run privacy:html` | `docs/privacy-policy.html` из тех же текстов, что в приложении |
| `npm run store:graphics` | скриншоты и feature graphic для Google Play |
| `npm run icons` | иконки, сплэш и favicon из SVG-знака |

Публикация и подключение сервера — в [PUBLISHING.md](PUBLISHING.md). Тексты для магазина — в [store/STORE_LISTING.md](store/STORE_LISTING.md).

## Где менять данные клиники

| Что | Файл |
| --- | --- |
| Название, контакты, адрес, часы работы, оплата, режим демо, канал заявок, видео | `src/config/clinic.ts` |
| Услуги и цены | `src/data/mock/services.ts` |
| Врачи и их расписание | `src/data/mock/doctors.ts` |
| Тексты главной и «О клинике» | `src/data/mock/clinicContent.ts` |
| Все надписи интерфейса | `src/i18n/ru.ts`, `src/i18n/ky.ts` |
| Цвета, шрифты, отступы | `src/theme/` |

Сейчас включён **демо-режим** (`isDemo: true`): врачи, цены, часы и адрес — примеры, в приложении видна плашка «Демо», а заявка отправляется в WhatsApp кнопкой вручную. Контакты настоящие.

## Архитектура

```
src/
  app/          маршруты Expo Router (каждый файл — одна строка экспорта экрана)
  screens/      экраны; screens/booking — шаги записи
  components/   ui (дизайн-система), brand (логотип, фон, графика), domain, booking, navigation
  theme/        токены: цвета, типографика, отступы, радиусы, тени, анимации
  i18n/         словари RU/KY, форматтеры дат и цен, кыргызские падежные аффиксы
  config/       clinic.ts — все данные клиники; app.ts — переменные EXPO_PUBLIC_*
  data/         справочник городов и демо-данные
  services/     интерфейсы репозиториев, mock/ и api/ реализации, доставка заявок, ссылки связи
  state/        React Context: настройки, профиль, записи, черновик записи, меню, тосты
  hooks/        загрузка данных с кэшем, статус клиники, связь, анимации
  utils/        время UTC+6, телефоны +996, сомы, валидация
tests/          тесты логики (node:test + tsx)
```

- Экраны не импортируют демо-данные и не вызывают `fetch`: данные идут через `services/` (`mock` или `api`, переключение в `services/index.ts`).
- Время считается по UTC+6 (Бишкек) независимо от часового пояса телефона.
- Свободное время считается детерминированно: часы клиники ∩ расписание врача − перерывы − занятые записи. Демо-занятость имитируется хэшем, только при `isDemo: true`.
- Строк интерфейса в компонентах нет, только `t.…`. Контент приходит как `{ ru, ky }`.
