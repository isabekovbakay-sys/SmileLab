# SmileLab

Android-приложение стоматологической клиники SmileLab (Бишкек) для пациентов.
React Native + Expo SDK 57 + TypeScript (strict). Два языка: кыргызский и русский.

Главная задача приложения — за минимум касаний довести пациента до записи или звонка в клинику.

## Что умеет

- **Главная**: герой с одной кнопкой «Записаться на приём», под ним — «Позвонить», WhatsApp, Telegram, «Адрес» (2ГИС или карта) и статус «Сегодня открыто до 19:00». Дальше — ближайшая запись, услуги и цены, врачи, «Не знаете, с чего начать?».
- **Запись за 3 шага**: услуга → день и время (врач — по желанию) → имя, телефон +996, короткий комментарий.
- **Без сервера — «желаемое время»**: сетка строится по часам работы клиники (без перерывов, прошедшего времени и минимального запаса), заявка открывается в WhatsApp с готовым текстом («Желаемое время: 30.09.2026, 15:00»), администратор подтверждает время или предлагает другое. С сервером (`EXPO_PUBLIC_DATA_SOURCE=api`) — настоящее свободное время.
- **Мои записи**: предстоящие и история, перенос, отмена, «Записаться снова», «Добавить в календарь» (Android).
- **Профиль**: имя и телефон подставляются в запись (хранятся в защищённом хранилище), язык, удаление всех данных с телефона.
- **Контакты, «О клинике», врачи, услуги с этапами и FAQ, политика конфиденциальности**, экран 404 и перехват ошибок.
- Пустые данные не показываются: нет Telegram — нет кнопки Telegram, нет адреса — нет 2ГИС и карты, нет врачей — нет блока «Врачи».

## Быстрый старт

```bash
npm install
npx expo start                          # реальные данные (пока пустые)
EXPO_PUBLIC_DEMO=1 npx expo start --clear   # демо: примерные услуги, врачи, часы
```

После смены `EXPO_PUBLIC_DEMO` всегда запускайте с `--clear`: Metro кэширует подставленное значение.

| Команда | Что делает |
| --- | --- |
| `npm run check` | типы (`tsc`), линтер (`eslint`), тесты логики (`node --test`) |
| `npm run release:check` | проверяет, что данные клиники заполнены для релиза |
| `npm run bundle:check` | собирает релизный бандл и проверяет, что в нём нет демо-данных |
| `npm run build:apk` | релизный APK через EAS (профиль `apk`) |
| `npm run build:aab` | AAB для Google Play через EAS (профиль `production`) |
| `npm run build:apk:demo` | демо-APK через EAS (профиль `demo`) — только для показа |
| `npm run build:apk:debug-local` | ⚠ локальный APK с **отладочным ключом** — только проверить на своём телефоне |
| `npm run bundle:android` | проверочный экспорт JS-бандла Android |
| `npm run privacy:html` | `docs/privacy-policy.html` из тех же текстов, что в приложении (нужно юрлицо) |
| `npm run ky:review` | `docs/ky-review.md` — таблица для вычитки кыргызского перевода |
| `npm run store:graphics` | скриншоты и feature graphic для Google Play |
| `npm run icons` | иконки, сплэш и favicon из SVG-знака |

Публикация и подключение сервера — в [PUBLISHING.md](PUBLISHING.md). Тексты для магазина — в [store/STORE_LISTING.md](store/STORE_LISTING.md).

## Где менять данные клиники

| Что | Файл |
| --- | --- |
| Контакты, адрес, 2ГИС, координаты, часы работы, юрлицо, оплата, канал заявок | `src/config/clinic.ts` |
| Услуги и цены | `src/data/clinic/services.ts` |
| Врачи и их расписание | `src/data/clinic/doctors.ts` |
| Тексты главной и «О клинике» | `src/data/clinic/content.ts` |
| Демо-данные (только демо-сборка) | `src/data/demo/` |
| Все надписи интерфейса | `src/i18n/ru.ts`, `src/i18n/ky.ts` |
| Цвета, шрифты, отступы | `src/theme/` |

Правило: **чего нет — оставьте пустым** (`null` или `''`). Приложение спрячет кнопку, а `release:check` не даст собрать релиз без обязательного (телефон, адрес, e-mail, юрлицо, цены, врачи, часы работы).

**Демо задаётся сборкой, а не кодом**: `EXPO_PUBLIC_DEMO=1` (профиль EAS `demo`) подключает `src/data/demo/`; в релизной сборке демо-модуля в бандле нет (проверяет `npm run bundle:check`).

## Архитектура

```
src/
  app/          маршруты Expo Router (каждый файл — одна строка экспорта экрана)
  screens/      экраны; screens/booking — шаги записи
  components/   ui (дизайн-система, ScreenContainer), brand, domain, booking, navigation
  theme/        токены: цвета, типографика, отступы, радиусы, тени, анимации
  i18n/         словари RU/KY, форматтеры дат и цен, кыргызские падежные аффиксы
  config/       clinic.ts — данные клиники; app.ts — переменные EXPO_PUBLIC_*
  data/         clinic/ — реальные данные, demo/ — демо (подключается только в демо-сборке)
  services/     репозитории (mock/ и api/), доставка заявок, ссылки связи, календарь, хранилища
  state/        React Context: настройки, профиль, записи, черновик записи, меню, тосты
  hooks/        загрузка данных с кэшем, статус клиники, связь, календарь, удаление данных
  utils/        время UTC+6, телефоны +996, сомы, валидация
scripts/        сборка, release-check, bundle-check, политика, вычитка KY, графика
tests/          тесты логики (node:test + tsx)
```

- Экраны не импортируют данные напрямую и не вызывают `fetch`: всё идёт через `services/` (`mock` или `api`).
- Время считается по UTC+6 (Бишкек) независимо от часового пояса телефона.
- Режим расписания: `slots` (сервер или демо: часы клиники ∩ расписание врача − перерывы − записи) и `request` (без сервера: «желаемое время» по часам клиники).
- Все экраны, шторки, футеры и таб-бар центрируются колонкой до 560 dp (`ScreenContainer`) с учётом вырезов и системных панелей в любой ориентации.
- Профиль — в `expo-secure-store`; записи на телефоне хранятся без номера телефона и комментария.
- Строк интерфейса в компонентах нет, только `t.…`. Контент приходит как `{ ru, ky }`.
